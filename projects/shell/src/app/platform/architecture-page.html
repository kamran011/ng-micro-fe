Integration contract · v{{ apiVersion }}

  • Exposes. Every remote exposes ./manifest (identity, version, contract major, owner) and ./routes (a standard Angular Routes).
  • Consumes. The shell provides SHELL_API: theme, track(), notify(). Remotes never touch shell internals.
  • Versioning. SHELL_API_VERSION is a major. Additive changes keep the major; breaking changes bump it and the shell refuses mismatched remotes (shown as incompatible) while the rest of the app keeps running.
  • Failure isolation. A remote that is offline degrades to a fallback page with retry. Its failure never blocks shell startup.
  • Shared. Angular, RxJS, NgRx Signals, @convo/contract and @convo/ds are singletons with strict versions, so there is one SHELL_API token and one design system at runtime.
  • Deploy. Each remote builds and ships on its own cadence; the shell only needs its entry in the manifest.
